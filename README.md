# 爱问答 · 网课学习助手

> 用户脚本**构建产物分发仓库**。本仓不含源代码。

## 安装

### 第 1 步：装一个脚本管理器

Tampermonkey 或脚本猫，任选其一。

### 第 2 步：打开「允许用户脚本」开关

Chrome 把用户脚本能力做成了**每个扩展一个开关，默认关闭**。它没打开时脚本一行都不会执行，而页面上不会有任何提示：没有面板、没有报错，看起来和「这个站点还没适配」一模一样。

- **Tampermonkey**：打开 `chrome://extensions/` → 找到 Tampermonkey → 「详情」→ 打开「允许用户脚本」→ 回到课程页刷新一次。
- **脚本猫**：同样进「详情」打开该开关，**然后把脚本猫这个扩展停用一次再重新启用**（脚本猫比 Tampermonkey 多这一步，不做的话开关不生效）。

如果你的浏览器里找不到这个开关，说明它不需要，跳过即可。

### 第 3 步：安装

👉 **[aiask.user.js（最新版本，自动跟随更新）](../../releases/latest/download/aiask.user.js)**

特定历史版本到 [Releases](../../releases) 列表下载对应的 `aiask-<版本>.user.js`。

装好后打开课程页面，右下角会出现面板。

## 适配范围

已适配**超星学习通**与**168 网校**，更多平台持续适配中。完整范围与逐项说明见官网 <https://www.aiask.site/>。

表外的平台不会注入，装了也不会出现面板。

## 你应当知道的两件事

脚本头部按脚本管理器的规范声明了两条 `@antifeature`，安装页会显示给你：

- **计费**：账号题库命中按积分计费，**未命中不扣分**；未登录时只查第三方免费题源，不扣分。
- **匿名上报**：上报仅用于定位识别规则失效以便远程修复，自动遮盖 token、Cookie、密码、卡密、签名等信息。更深的页面信息只在你确认之后才会上传。

默认行为（都能在面板「系统 · 设置」里关）、计分细则与答案边界见官网与安装后的面板说明。
