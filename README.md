# 爱问答 · 网课学习助手

在网课页面识别题目、查找答案并辅助填写，自动收录已公布的答案，也能按平台支持范围推进视频、音频和文档学习任务。

自动提交开关默认开启，仅在已支持该操作的非考试页面生效。希望自己确认时，请先在设置中关闭。**考试卷不会自动交卷。**

## 安装

先安装 Tampermonkey 或脚本猫，再选择一个安装入口：

- **[GitHub：安装最新正式版](https://github.com/aiaskhelper/aiask-dist/releases/latest/download/aiask.user.js)**
- [脚本猫](https://scriptcat.org/zh-CN/script-show-page/7766)
- [Greasy Fork](https://greasyfork.org/zh-CN/scripts/593758)

商店可能稍晚同步新版本。[历史版本与更新说明](https://github.com/aiaskhelper/aiask-dist/releases)可随时查看。

### 首次安装后

1. 打开浏览器扩展管理页，进入脚本管理器的详情，打开「允许用户脚本」或「允许运行用户脚本」。若浏览器没有这个开关，可跳过。
2. 使用脚本猫时，再停用、重新启用一次扩展。
3. 安装脚本，回到支持的课程或题目页面刷新。
4. 右下角出现爱问答面板后，即可查看题目、答案和处理进度。首次使用会自动同步识别规则。

Chrome 的扩展管理页地址是 `chrome://extensions/`。没有打开用户脚本权限时，页面上可能既没有面板，也没有报错。

## 能帮你做什么

- **辅助答题**：识别当前页面的题目，查询答案并自动填写。答案与题目或选项无法可靠对应时会留空，便于你自行核对。
- **答案收录与备份**：在支持的结果页收录已公布答案，之后遇到相同题目可使用本机缓存；支持导入、导出。
- **课程学习**：在已适配的页面推进视频、音频、文档等任务，可暂停或关闭；各平台支持的任务不同。
- **AI 补答**：题库未完成的题目可交给你配置的 AI，使用方式可选关闭、仅手动或自动补答。
- **AI 讲解与追问**：围绕单道题查看解题思路、继续提问，发送前可预览，也可取消。讲解不会改写卷面答案。

## AI 怎么用

在面板「系统 · AI」配置服务和模型，先测试连接，再选择使用方式。

- **云端服务**：需自备服务商 Key，也可配置自定义 AI 接口。调用时，Key 和题目会经爱问答转发；服务端不留存 Key。
- **本机网关**：可使用你在自己电脑上运行的 AI 网关，不要求爱问答登录。题目直接发给该网关，但网关仍可能转发到云端模型或搜索服务。
- **图片题**：先测试当前模型的图片能力，再预览并确认要发送的图片。图片自动补答默认关闭，需要另外开启。
- **停止与继续**：答题过程中可以停止，之后继续处理尚未完成的题目；修改 AI 配置会停止当前任务。
- **答案保存**：AI 答案是否保存到本机、是否共享到云端可分别选择。讲解对话不会保存成答案缓存。

AI 需要你自行配置可用的服务。第三方模型和搜索费用由所选服务结算，停止请求也可能已经产生费用；AI 答案和讲解均请自行核对。

## 支持哪些平台

超星学习通、168 网校、湖北自考助学平台、江苏开放大学、国家开放大学、广东开放大学、安徽继续教育在线新版、柠檬文采、UMU 互动平台、青书学堂、云班课。

同一平台的答题、答案收录和课程学习支持范围各不相同，平台名称不表示所有学校、页面、题型都支持。具体功能见[脚本猫详细说明](https://scriptcat.org/zh-CN/script-show-page/7766)。

其他答题平台也可查看[爱问答助手](https://github.com/aiaskhelper/ai-ask-helper-dist)的支持范围。

## 使用时请留意

- **考试卷不会自动交卷**。已支持自动提交的页面会按设置执行，未达到提交阈值时只暂存。需要自己确认时，可关闭自动提交。
- 自动课程学习可在面板暂停；具体开关在「系统 · 课程」。
- 本机缓存不会自动跟随电脑或浏览器迁移。换设备或重装前，请在「系统 · 缓存」导出备份。
- 题库积分、AI 服务费用及数据使用说明，以面板和官网当前说明为准。

## 遇到问题

先确认用户脚本权限已开启、脚本已启用，并刷新支持的页面。平台改版后，可在「系统 · 通用 · 规则更新」检查更新。

反馈时请附上平台名称、页面类型、脚本版本和问题现象，截图注意遮挡个人信息。

- [官网](https://www.aiask.site/)
- [反馈与帮助](https://www.aiask.site/contact.html)

本脚本仅供学习与交流使用，答案不保证正确。请遵守目标平台的使用规则，自行核对并承担使用后果。
